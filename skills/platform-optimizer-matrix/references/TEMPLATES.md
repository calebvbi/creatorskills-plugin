## Quick Reference: Platform Cheat Sheet

Keep this visible during content planning. One line per platform with the most important numbers.

```
PLATFORM QUICK REFERENCE

YouTube (Long-Form)
  Post: 1-2x/week | Format: 8-20 min | Key metric: AVD >50%, CTR >5%

YouTube Shorts
  Post: 3-7x/week | Format: 30-45 sec vertical | Key metric: Swipe-away <30%

TikTok
  Post: 5-7x/week (min 4) | Format: 15-60 sec | Key metric: Completion rate, shares

Instagram Reels
  Post: 3-5x/week | Format: 15-60 sec | Key metric: Shares, saves

Instagram Carousels
  Post: 2-3x/week | Format: 7-10 slides | Key metric: Save rate >5%

LinkedIn
  Post: 3-5x/week | Format: Text posts, doc carousels | Key metric: Dwell time, comments

Twitter/X
  Post: 3-10x/day | Format: Threads (8-12 tweets), singles | Key metric: Bookmarks, replies

Newsletter
  Post: 1x/week | Format: 500-1000 words | Key metric: Open rate >40%, CTR >2%

Podcast
  Post: 1x/week | Format: 30-60 min | Key metric: Downloads, clip performance
```
