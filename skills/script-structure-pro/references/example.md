# Script Structure Pro: grounded tutorial and opinion structures

## Example 1: tutorial excerpt

**Supplied brief:** Show how to prepare a batch export in Lightroom. Key points are choosing output settings, making an export preset, using batch export and reviewing the results. The creator targets six minutes. No software version, timings, experience history or technical test data are supplied.

### Three opening options

- “Before you export a whole batch, decide where those images will be used.”
- “This walkthrough turns your export choices into a checklist you can repeat.”
- “Start with one sample export, check it, then apply the settings to the rest.”

### Structure

**Setup:** “The right settings depend on the destination. Start by checking its requirements rather than copying a preset without reviewing it.”

**Point 1: choose settings.** Explain the intended destination and identify the fields the creator will demonstrate. Verify actual controls in the version being used before recording specific interface steps.

**Transition:** “Once those choices are made, you can save a starting point for the next batch.”

**Point 2: create the preset.** Demonstrate the actual preset creation flow in the creator's software. [Interface steps to confirm.] Explain which choices may need changing for a different destination.

**Point 3: export and review.** “Check a sample result before applying the settings to a large group. Does it meet the destination's requirements and your visual expectations?”

**Payoff:** “You now have a repeatable sequence: choose, save, export and inspect.”

**CTA:** “Try the sequence on a small set before using it for your next large export.”

**Production notes:** This is an excerpt and structure, not a complete six-minute script. The six-minute target is unverified; count the final narration and time a read-through. Record actual interface footage. No personal mistake story, 80% success metric, export speed claim or unsupported compression explanation was added.

## Example 2: opinion without invented biography

**Supplied brief:** The creator thinks beginners should prioritize finishing small projects before buying more gear. They have not supplied a personal story or supporting data.

**Hook:** “Before your next gear purchase, choose one small project you can finish with what you have.”

**Setup:** “This is a practical suggestion, not a rule that equipment never matters. The goal is to learn which limitation you actually encounter.”

**Point 1:** Define a small deliverable, such as a short portrait session or a one-minute video.

**Point 2:** List what the current setup can do and identify any essential missing capability.

**Point 3:** Finish the project, then write down the specific problem a purchase would solve.

**Counterpoint:** “If an essential tool is missing, renting or borrowing may help you test the need before buying.”

**Payoff:** “A completed project gives you a concrete basis for deciding what comes next.”

**CTA:** “Name the project first. Then decide which tool, if any, it needs.”

**Evidence status:** This is a proposed process based on the creator's stated opinion. It claims no measured improvement, client experience or personal spending history.
