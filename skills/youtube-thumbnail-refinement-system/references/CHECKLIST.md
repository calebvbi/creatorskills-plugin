# YouTube Thumbnail Refinement Checklist

Use this checklist before you tell a creator to publish a thumbnail.

If the draft fails two or more items in the **Hard Fail** section, move to a partial rebuild or full rework.

## 1. Hard Fail Trust Killers

- Face looks uncanny, plastic, or emotionally dead
- Hands, teeth, device edges, or props are warped
- Fake UI or fake screenshots are visible
- Text is baked into the generated image
- Lighting feels glossy and synthetic instead of deliberate
- There are too many objects fighting for attention
- The focal subject is unclear at mobile size

## 2. Hook Clarity Check

- Can a viewer understand the thumbnail in 0.5 seconds?
- Is there one dominant focal story?
- Does the thumbnail add tension, curiosity, or clarity beyond the title?
- Would the thumbnail still work with less text?
- Does the main subject take up enough space to read on mobile?

## 3. Channel Consistency Check

- Does it still look like the creator's channel?
- Is there at least one repeatable brand trait present?
- Does the color treatment feel intentional instead of random?
- Would this thumbnail look out of place beside the creator's last five uploads?

## 4. Typography Check

- Overlay text is added manually, not generated
- Text is 0 to 4 words unless there is a very good reason otherwise
- Text complements the title instead of copying it word-for-word
- Contrast is strong enough to read at mobile size
- Placement does not block the face, product, or proof element

## 5. Real Asset Swap Check

Replace generated elements with real assets when any of these are true:

- the face must feel trustworthy
- the product or device shape is important
- the app UI or analytics proof must be credible
- the logo or interface details matter to the promise

Real assets usually beat regeneration loops when trust is the problem.

## 6. Manual Polish Pass

- Crop tighter before adding more elements
- Remove one non-essential object
- Darken or blur the background behind the main subject
- Add outlines or glow to only one focal element
- Use a real text layer with clean spacing
- Check the thumbnail at small size before export

## 7. A/B Discipline

Only test one major variable at a time:

- crop
- text density
- contrast intensity
- subject scale
- emotion intensity
- background simplicity

Do not test a totally different concept and call it a clean A/B result.
