# Prepare Channel Brand Kit

Product description: Get a matching set of channel art: banner, offline or end screen, panels, and avatar: all built from one locked brand direction.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Channel name | Required | Exactly as it should appear on the banner. This is the one word on the page a viewer has to remember. |
| What the channel is about | Required | One sentence. "Weekly souls-game boss-fight streams" produces art specific to you; "gaming" produces the generic banner every gaming channel already has. |
| Platform | Required | Sets the canvas sizes and safe areas. YouTube needs a banner plus an end screen; Twitch needs a banner, an offline screen, and the five-panel stack. Pick "both" and we build the set so the two channels look like one brand. Options: youtube, twitch, both. |
| Three words for the vibe | Required | "Moody, technical, calm" and "loud, colorful, chaotic" are different channels. This is what stops the palette being a guess. |
| Brand colours you already use | Optional | Hex codes if you have them. Leave it blank and we pick a palette that fits the niche and the vibe, but never overwrite recognition you have already built. |
| What the avatar should be | Optional | Uploads are not available yet, so a stylized portrait is generated from your description rather than from a photo of you. If you want your actual face, use the layout spec we return and drop your own cutout in: the spec is built for it. Options: mascot, icon_mark, monogram, stylized_portrait. |
| Anything to avoid | Optional | Colours, styles, or the clichés of your niche you are sick of. "No neon gaming aesthetic" is a useful instruction. |
| Tagline or upload schedule | Optional | "New videos every Tuesday & Friday", or a one-line promise. This goes in the safe area, which is the only part of a YouTube banner every device is guaranteed to show. |
| Handles to display | Optional | These sit in the desktop-only right third of a YouTube banner, or the Socials panel on Twitch. Never in a zone that carries required reading. |
| Stream schedule | Optional | Days and times for the Schedule panel and the offline screen. An offline screen that does not say when to come back is a wasted screen. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Channel Brand Kit](https://creatorskills.co/create/channel-brand-kit) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
