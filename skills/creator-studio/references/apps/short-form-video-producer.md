# Prepare Short-Form Video Producer

Product description: Turn a week of posting into a shoot: a calendar that rotates formats so your feed stops repeating itself, a full timed script for every video with the visual cue and on-screen text for each beat, the captions and hashtags, and the batching plan that films all of them in one sitting.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What you make, and who watches | Required | Be specific: "personal finance for 20-somethings on their first salary" beats "finance". This decides the vocabulary, how much we can assume they already know, and which of the twelve formats actually fit you. |
| Where you post | Optional | Changes hook speed, caption length and hashtag count: TikTok wants the hook inside two seconds and a caption under 150 words, Reels gives you three seconds and a caption you can write 300 words in. Defaults to multi-platform. Options: tiktok, youtube_shorts, instagram_reels, multi. |
| How many videos this week | Optional | Be honest rather than aspirational. Three filmed beats seven planned, and the calendar is built around what you will actually shoot in one session. Defaults to 3. Options: 1, 2, 3, 4, 5, 7. |
| What this week is for | Optional | Drives the CTA, and only one CTA gets written per video. Stacking asks is why most short-form outros get skipped. Options: followers, views, saves, comments, link_clicks, sales. |
| Usual video length | Optional | Seconds. Sets the spoken word budget for every script: a 60-second script is 140-165 words, not "about a minute of talking". Individual videos still move off this where the format demands it. Defaults to 30. Options: 15, 30, 45, 60, 90. |
| Topics you already want to cover | Optional | One per line. Anything here gets its own video before we propose new ones. Include the specifics you would say on camera: a number, a result, a tool name: because we will not invent one for you. |
| How you shoot | Optional | Changes the visual direction and which formats we pick, not the words. Say text_overlay if you hate being on camera and no script will ask you to be. Options: talking_head, text_overlay, tutorial, pov, b_roll_voiceover, mixed. |
| Editing setup | Optional | A beginner gets cut patterns and text timing that CapCut can do on a phone. Nothing in the production notes will assume a keyframe you cannot set. Options: beginner_capcut, intermediate, advanced. |
| Time you can spend per video | Optional | Under fifteen minutes and the calendar weights toward formats that shoot in one take. This is the input that decides whether the week is realistic. Options: under_15m, 15_30m, 30_60m, over_60m. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Short-Form Video Producer](https://creatorskills.co/create/short-form-video-producer) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
