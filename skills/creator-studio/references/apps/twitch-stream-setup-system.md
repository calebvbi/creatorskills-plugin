# Prepare Twitch Stream Setup System

Product description: Go from a fresh OBS install to a stream that looks and sounds professional: encoder and bitrate matched to your actual hardware, five scene layouts with element positions, an audio chain that stops the game drowning you out, and a go-live checklist you never go live without.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Your computer, camera and microphone | Required | CPU, GPU, RAM, camera and mic, as specifically as you can. "Ryzen 5 5600X, RTX 4060, 16GB, Logitech C920, Blue Yeti" gets you real encoder settings. "A gaming PC" gets you a guess, and we will tell you it is a guess rather than dressing it up as a spec. |
| Upload speed | Optional | Run speedtest.net and give us the UPLOAD number in Mbps, not download. This is the single number that decides your bitrate, and getting it wrong is why streams buffer. Leave it blank and we plan conservatively and tell you what to re-check. |
| Streaming software | Optional | Every setting below is named in that program's own vocabulary, because a setting you cannot find is a setting you do not change. Undecided gets a recommendation first. Options: obs, streamlabs, streamelements, twitch_studio, xsplit, undecided. |
| What you stream | Optional | Decides the scene list and the layout. A Just Chatting scene is a full-frame camera; a gaming scene is a corner camera and a chat widget you can read without turning your head. Options: gaming, just_chatting, creative, music, irl, hybrid. |
| Where you are starting from | Optional | Changes how much is explained and how much is just handed to you. A first-timer gets the click path; a regular streamer gets the values. Options: never_streamed, occasional, regular_levelling_up. |
| Do you have a second monitor | Optional | With one, chat and the activity feed live off-canvas. Without one, they have to be in the scene or on a phone, and that changes every layout. |
| What you can spend on this | Optional | Free-only is a fully supported answer, not a downgrade: every paid recommendation we make comes with the free alternative next to it and what you actually lose by taking it. Options: free_only, under_50, under_200, no_limit. |
| Three words for how the channel should feel | Optional | "Dark, technical, calm" and "bright, chaotic, funny" produce different overlays and different accent colours. This is what stops the overlay recommendation being the same one everyone gets. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Twitch Stream Setup System](https://creatorskills.co/create/twitch-stream-setup-system) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
