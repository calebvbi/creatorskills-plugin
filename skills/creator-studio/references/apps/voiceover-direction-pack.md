# Prepare Voiceover Direction Pack

Product description: Turn a script that reads fine on the page into narration that sounds like a person: rewritten for the ear, marked with every pause and emphasis, and paired with the exact engine settings to paste into ElevenLabs or OpenAI TTS.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Script, outline, or topic | Required | Paste a full script and we rewrite it for the ear. Paste bullets and we flesh them out. Give us a topic in one line and we write the narration from scratch. All three work: the more you paste, the more of your own thinking survives into the recording. |
| Target runtime | Optional | Minutes. Narration runs about 140 words a minute, so this sets the word count directly: 6 minutes is roughly 850 spoken words, 20 is roughly 2,800. Defaults to 12. Options: 3, 6, 12, 20. |
| How the narrator should sound | Optional | Leave it blank and we pick from the content and tell you why. Procedures get The Expert, mysteries get The Storyteller, money and health get The Quiet Authority, dense systems get The Professor. Options: the_expert, the_storyteller, the_hype_man, the_quiet_authority, the_casual_friend, the_professor. |
| Voice engine you use | Optional | Changes the settings block at the end. ElevenLabs gets stability, similarity and style numbers; OpenAI TTS gets voice and speed; a human voice actor gets a direction sheet instead of numbers. Options: elevenlabs, openai_tts, murf, play_ht, human_voice_actor, undecided. |
| What kind of video this is | Optional | Sets words per minute and how hard the pacing leans. Shorts run fast and flat-out; documentary narration breathes. Options: tutorial, explainer, documentary, review, faceless_long_form, shorts. |
| Words the engine always gets wrong | Optional | Names, brands, acronyms, anything foreign. One per line. These become pronunciation flags in the brief so you stop re-rendering the same line. |
| A channel whose narration you want to sound like | Optional | "Calm and authoritative like Vsauce" or "punchy like Mrwhosetheboss". We match the delivery pattern, never the person: we will not imitate a named creator's voice, only the pacing and energy shape. |
| Keep my exact wording where it already works | Optional | On, we only change what the ear needs changed and flag every line we touched. Off, we rewrite freely for delivery. Default is on when you pasted a full script. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Voiceover Direction Pack](https://creatorskills.co/create/voiceover-direction-pack) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
