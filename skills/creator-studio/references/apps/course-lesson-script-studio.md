# Prepare Course Lesson Script Studio

Product description: Turn one lesson title and its objective into a camera-ready lesson script: a hook that earns the first minute, a stated promise the summary closes, a mid-lesson exercise the student actually does, and a bridge that pulls them into the next lesson.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What is this lesson called? | Required | The narrower the better. "Set exposure in manual mode in three steps" gives you a lesson; "Photography Basics" gives you a rambling twenty minutes. If your title is broad we will narrow it and tell you what we cut. |
| What will students be able to DO afterwards? | Optional | A verb, not a state. "Correctly expose a photo in manual mode in three steps" is an objective; "understand exposure" is not. Leave it blank and we will write one from the title, and we will say so rather than pretending you gave us one. |
| Who is watching | Optional | Sets vocabulary, what we assume you can skip explaining, and how many points fit in a section. Beginners need fewer points explained more slowly; advanced students resent being walked through the basics. Defaults to beginner. Options: beginner, intermediate, advanced. |
| Target length | Optional | Minutes. Natural teaching speech runs about 130 words a minute, so this sets the word count directly: 5 minutes is roughly 650 spoken words, 20 is roughly 2,600. Defaults to 10. Options: 5, 10, 20. |
| How you teach on camera | Optional | Conversational is contractions and short sentences. Structured is numbered steps and explicit transitions, and suits process-heavy or technical material. Story-driven opens on a scenario and keeps the thread running. Pick match_my_channel if we have your voice on file. Options: conversational, structured, story_driven, match_my_channel. |
| Notes, bullets or an outline you already have | Optional | Paste anything: rough bullets, an old outline, the lesson plan from your curriculum. We build the script around your thinking instead of starting over, and any phrase or analogy you already use gets kept rather than replaced with ours. |
| Where this lesson sits in the course | Optional | Course name, module, lesson number, and what the lesson before this one covered. This is the field that lets us stop re-explaining what students already learned: paste the module map straight out of your curriculum plan if you have one. |
| What the next lesson covers | Optional | The bridge at the end of the script is written to make students want this specific next lesson. Without it we write a general forward-look, which is weaker and we will say so. |
| One thing they should do before the next lesson | Optional | The summary ends with exactly one action. Name it here if you already know it; leave it blank and we propose one that can be done with what the student already has. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Course Lesson Script Studio](https://creatorskills.co/create/course-lesson-script-studio) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
