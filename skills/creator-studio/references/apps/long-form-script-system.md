# Prepare Long-Form Script System

Product description: Turn a video idea into a complete, ready-to-film YouTube script: every word you say, with hook options, retention loops every few minutes, energy cues, B-roll callouts, and one CTA that lands.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What is this video about? | Required | Be specific: "why I switched back to a $300 phone after two years on flagships" beats "phone review". A couple of sentences is plenty. |
| Video type | Optional | Decides the narrative structure. Leave it blank and we'll pick the structure that fits your topic and say why. Options: tutorial, product_review, storytelling, listicle, commentary. |
| Target length | Optional | Minutes. Drives the word count, the number of body sections, and how often the retention loops land. Defaults to 15. Options: 10, 15, 20, 30. |
| Niche | Optional | Each one has its own hook style, pacing tolerance and outro convention: gaming audiences want stakes up front, business audiences want the thesis in the first 30 seconds. Options: gaming, educational, lifestyle, business, other. |
| Who watches you | Optional | What they already know and why they care: "first-time founders who have never hired anyone" tells us how much to explain and which words to skip defining. |
| How you sound on camera | Optional | We write the words you will actually say, so this changes sentence length, rhythm and how blunt the script gets. Defaults to conversational and confident. Options: casual_funny, calm_authoritative, high_energy, analytical, warm_conversational. |
| Points you have to cover | Optional | Talking points, a sponsor segment, a conclusion you have already committed to. One per line. These get their own beats rather than being squeezed in. |
| Outline or draft you already have | Optional | Paste bullets, a rough structure, or a full draft that feels flat. We keep your structure and build the hooks, loops, pacing and visual layer around it instead of starting over. |
| The one thing you want viewers to do | Optional | Exactly one CTA gets written, whichever you pick. Stacking asks is why most outros get skipped. Options: subscribe, watch_next_video, get_the_resource, comment, join_email_list, buy_the_product. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Long-Form Script System](https://creatorskills.co/create/long-form-script-system) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
