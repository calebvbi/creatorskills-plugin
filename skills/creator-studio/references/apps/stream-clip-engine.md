# Prepare Stream Clip Engine

Product description: Stop letting four hours of stream expire with the VOD: get the moments worth cutting named with timestamps, an edit template that turns each one around in fifteen minutes, the export specs each platform actually wants, and a weekly batch session that fits the hours you really have.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What you stream and how often | Required | Content, cadence, session length, rough audience size. "Valorant four nights a week, three to four hours, about 150 concurrent" gets a workflow built for you; "I stream games" gets the generic one. |
| Transcript of a recent stream | Optional | Paste a timestamped transcript and we name the actual moments worth clipping, with the timestamp and the reason. Leave it blank and you still get the spotting rubric: the 8 moment types and the six-point quality check: so you can do one VOD pass yourself. We never pretend to have watched a stream you did not paste. |
| Where the clips go | Optional | Changes clip length, caption style, hashtag counts and posting times. Defaults to all three, with the differences called out rather than averaged into one wrong spec. Options: tiktok, youtube_shorts, instagram_reels, all_three. |
| Hours a week you can give to clipping | Optional | The calendar is built to this number and its own estimates are summed against it. This is the input most clipping plans skip, and it is why most clipping plans get abandoned in week three. Options: 1, 2, 4, 8. |
| How comfortable you are editing | Optional | Decides which editor you are pointed at and how much of the template is click-by-click. A beginner gets CapCut with the taps named; an advanced editor gets the settings and nothing else. Options: never_edited, basic_trimming, comfortable, advanced. |
| Tools you already have | Optional | Software, subscriptions, a Stream Deck, a mod who clips for you. We build the workflow around what you own before recommending anything new, and any paid suggestion comes with the free alternative. |
| What the clips are for | Optional | A clip cut to be discovered by strangers and a clip cut to pull existing followers into a live stream have different hooks and different CTAs. Defaults to discovery. Options: discovery_growth, drive_live_viewers, sponsor_reel, community_highlights. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Stream Clip Engine](https://creatorskills.co/create/stream-clip-engine) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
