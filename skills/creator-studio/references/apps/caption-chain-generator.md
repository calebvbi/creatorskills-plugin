# Prepare Caption Chain Generator

Product description: A month of captions written and dated: thirty slots across ten rotating frameworks so the feed stops sounding copy-pasted, each caption in your voice with its own CTA, and a hashtag bank grouped by theme so you are not reusing the same twenty tags.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Your niche, and who follows you | Required | "Home workouts for women 25-40 who have twenty minutes and no equipment" gives thirty specific captions. "Fitness" gives thirty generic ones. Include what they are actually trying to do, not just who they are. |
| Where these are going | Optional | Both writes each slot natively rather than one caption reformatted: Instagram tolerates messy and personal, LinkedIn does not, and the same words on both is the fastest way to look automated. Defaults to Instagram. Options: instagram, linkedin, both. |
| How you sound | Optional | Give an example rather than an adjective. "I write like I'm texting a friend" or "blunt, short sentences, no exclamation marks" gets you closer than "casual". Better still, paste two captions you already wrote and liked. |
| Topics you already rotate through | Optional | One per line, if you have them. We build three to five pillars either way; supplying yours means the month is organised around what you already post rather than around what we guessed. |
| What this month is for | Optional | Weights the framework rotation. Saves pull toward value posts and carousels; comments pull toward questions and hot takes; sales still caps promotional posts at four for the month. Options: followers, saves, comments, dms, email_signups, product_sales. |
| What you are selling, if anything | Optional | The offer, who it is for, and one real proof point. Leave it blank and the promotional slots become value posts instead: we will not invent a testimonial or a result to fill them. |
| Real milestones or client results you can name | Optional | One per line: "hit 10K in March", "Sam went from 0 to 12 clients in four months, he said the pricing script was the unlock". These are the only source for the milestone and testimonial slots; without them those frameworks are swapped out rather than filled in. |
| What day to start on | Optional | Any format we can read: "March 3" or "next Monday". Used to date the slots and to keep LinkedIn off weekends. Defaults to day 1 through day 30 with no dates attached. |
| Days you can realistically post | Optional | "Weekdays only" or "Mon Wed Fri". The calendar is built around this instead of assuming daily, because a plan you miss on day four is worse than a shorter one you keep. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Caption Chain Generator](https://creatorskills.co/create/caption-chain-generator) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
