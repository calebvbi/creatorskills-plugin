# Prepare Thumbnail A/B Test Analyzer

Product description: Turn your thumbnail test numbers into a decision, which variant won, whether the result is real, and what to test next.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Impressions and clicks per variant | Required | One line per thumbnail. Paste it straight out of YouTube Studio: "A: 2847 impressions, 312 clicks". CTR percentages alone are not enough: we need the raw counts to tell a real difference from noise. |
| Video title | Optional | The title that ran alongside these thumbnails. A thumbnail is never judged on its own: half of CTR is whether the two say different things. |
| What did you change between variants? | Required | The click-through arithmetic is identical either way: impressions and clicks do not care which half of the packaging moved. This decides what the diagnosis is allowed to talk about, and it is required rather than inferred because a readout that blames the thumbnail for a title test is worse than no readout. Options: thumbnail, title, both. |
| Describe each variant | Optional | Uploads are not available yet, so describe each variant in a sentence instead. Thumbnail test: what is in frame, the expression, the overlay words, the dominant colours: "A: me mid-shrug, left third, 'I QUIT' in yellow on navy." Title test: paste the titles verbatim. Both: give the pair per variant. Without this you still get the maths and the verdict, just not the why. |
| Platform | Optional | Sets the CTR benchmark band we score you against. YouTube's 4-6% "decent" range is not TikTok's. Options: youtube, tiktok, instagram, other. |
| Niche | Optional | Benchmarks move by category. Gaming and finance channels do not share a normal CTR. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Thumbnail A/B Test Analyzer](https://creatorskills.co/create/thumbnail-ab-test-analyzer) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
