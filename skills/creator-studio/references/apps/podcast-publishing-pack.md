# Prepare Podcast Show Notes & Publishing Pack

Product description: Turn a finished episode into everything that ships with it: searchable show notes with real chapter timestamps, quotes pulled verbatim, the resource list, three platform-native captions and the teaser scripts for the clips.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| The episode | Required | Paste the transcript if you have one: that is the best input and it skips transcription entirely. An outline or rough notes also work, and you get the same package with chapter times clearly marked as estimates for you to fix after you check the file. If you would rather upload the audio, put a short note here and use the file or link field below. |
| Audio or video file | Optional | Upload the recording and we transcribe it. Use this when you have no transcript. On the free tier we transcribe the first twenty minutes; paste a transcript instead if your episode is longer. |
| Link to the published episode | Optional | A public episode URL we can pull audio from, if you would rather link than upload. One of a transcript, a file, or a link is needed. |
| Episode title | Optional | Leave it blank and we propose one under sixty characters and show why. Give us yours and we keep it exactly as written, even where it is longer than we would choose. |
| Episode number | Optional | Used in the header line and in the title tag where it still fits inside the character limit. |
| Podcast name and what it covers | Optional | Sets the tone of the summary and the register of the captions. A true-crime show and a B2B SaaS show describe the same forty minutes very differently. |
| What this episode should rank for | Optional | The phrase someone would actually type: "grow a podcast without ads" rather than "podcasting". It goes into the first hundred words naturally or not at all; we never wedge it in. |
| Guest name, role, and where to find them | Optional | Their title, what they are known for, and their links. This is the only source for the guest bio: we write it from what you paste and what they say on tape, and we will not fill in a credential we were not given. |
| Links for anything mentioned | Optional | One per line, as "name: URL". We build the resource list from what is actually said in the episode; this is where the URLs come from, so anything without one is listed by name with the link left for you. |
| What you want listeners to do | Optional | One primary CTA gets written into the notes and into every caption. A block of five links at the bottom of an episode page converts on none of them. Options: subscribe, join_email_list, buy_or_book, join_community, leave_a_review, listen_to_related_episode. |
| Where the captions are going | Optional | All three by default, each written natively rather than one caption reformatted: the three platforms reward completely different opening lines. Options: all, instagram_only, twitter_only, linkedin_only. |
| Where the notes are going | Optional | Apple and Spotify strip markdown and cut off at four thousand characters, so that variant is written in plain text with the strongest content inside the first two hundred and fifty characters where the collapsed view ends. Options: website_markdown, apple_and_spotify_plain_text, substack_newsletter, all. |
| How the show sounds | Optional | Matters most for the captions and the teaser scripts, which are the artifacts a listener hears in your voice rather than reads. Options: conversational, warm_reflective, high_energy, deadpan_dry, journalistic, match_my_show. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Podcast Show Notes & Publishing Pack](https://creatorskills.co/create/podcast-publishing-pack) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
