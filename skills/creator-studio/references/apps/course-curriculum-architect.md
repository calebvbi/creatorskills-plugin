# Prepare Course Curriculum Architect

Product description: Turn what you know into a course you can actually build: named modules, written lesson plans with objectives and activities, a price your audience will pay, and the six launch emails that sell it.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What do you teach? | Required | Be specific. "Off-camera flash portrait photography for beginners" builds a far better course than "photography". A paragraph works better than a phrase. |
| Who takes this course? | Optional | What they already know, what they want, and where they get stuck. This is the one question we would otherwise have to ask you. |
| Course format | Optional | Changes pacing, engagement design, and the launch sequence. Defaults to self-paced. Options: self_paced, cohort, hybrid, membership_drip. |
| Where you'll host it | Optional | Platform constraints shape module structure, quiz format, and how the community works. Leave it blank and we'll write it platform-neutral. Options: teachable, kajabi, skillshare, thinkific, podia, youtube_membership, notion, other, undecided. |
| Target price | Optional | Price sets the required depth, lesson length, and support level. If your price and your scope don't match, we'll say so rather than quietly building the wrong course. Options: under_29, 30_97, 98_297, 298_997, over_1000. |
| Content you already have | Optional | YouTube videos, blog posts, newsletter issues, templates. Say roughly how many and what they cover: repurposing cuts production time in half and we'll map it module by module. |
| Audience size | Optional | Drives the launch plan and the realistic first-launch revenue estimate. Options: under_1k, 1k_10k, 10k_50k, 50k_250k, over_250k. |
| Where your audience lives | Optional | Example: 14K YouTube subs, 2,300 email list, small Instagram. The launch sequence is written for the channels you actually have. |
| When do you want to launch? | Optional | Decides whether you should build the whole course first or pre-sell a beta cohort and build as it runs. Options: presell_now, within_1_month, within_3_months, no_deadline. |
| This is my first course | Optional | Turn this on and we'll plan a beta cohort instead of a full build: pre-sell a small group, build week by week, and let their feedback shape the modules before you record finals. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Course Curriculum Architect](https://creatorskills.co/create/course-curriculum-architect) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
