# Prepare SEO Title & Description Writer

Product description: Turn a topic and a target keyword into three publish-ready title and description pairs that fit the platform's character limits, match the search intent behind the keyword, and read like a person wrote them.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Topic, working title, or content brief | Required | What the video, post, or episode is actually about. A sentence is enough; a full brief works better. |
| Target keyword | Optional | The exact phrase you want to rank for. Leave it blank and we'll pick the most natural one from your topic and tell you why. |
| Where this is publishing | Optional | Character limits and description rules differ by destination. Defaults to blog post formatting if omitted. Options: youtube, blog, podcast. |
| Audience, niche, or competitors | Optional | Who this is for, and what the results you're competing against look like. This is the one question we'd otherwise ask you. |
| Brand, channel, or show name | Optional | Used for pipe-separated branding on blog title tags and for podcast episode numbering. Only used when it still fits the character limit. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [SEO Title & Description Writer](https://creatorskills.co/create/seo-title-description-writer) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
