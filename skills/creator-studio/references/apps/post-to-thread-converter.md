# Prepare Post-to-Thread Converter

Product description: Turn one thing you already published into the two posts it earns: an X thread built as an argument rather than a list, every tweet counted against the 280-character limit, and a LinkedIn post whose first line survives the "See more" cut.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| The thing you published | Required | Paste the whole thing: the full blog post, the full transcript, the full newsletter. Do not summarise it first: the job here is finding the best angle buried in paragraph seven, and a summary has already thrown that away. Messy transcripts are fine. |
| What kind of thing it is | Optional | Leave it blank and we work it out from the text. It only changes what gets discarded: a transcript has sponsor reads and "let's get into it" filler that a blog post does not. Options: blog_post, newsletter, video_transcript, podcast_transcript, rough_notes, topic_description. |
| Title of the original | Optional | Used to frame the thread and to write the close tweet. Not used as source material: a title alone is never enough to write from. |
| Link back to the original | Optional | Goes in the close tweet, framed as "more detail" rather than "the same thing again". We never read it: if this is all you have, paste the transcript instead and we will say so rather than guessing. |
| How you write | Optional | One sentence is enough: "casual and a bit sarcastic", "technical audience, no hype". Mostly we take your voice from the source text itself; this only helps where the source is rough notes. |
| What you want out of it | Optional | Decides the close tweet and the LinkedIn closer. One ask, not three. Options: reach, profile_visits, newsletter_signups, watch_the_video, read_the_post, replies. |
| Which formats you need | Optional | Both by default, written natively rather than one reformatted into the other: the two platforms reward completely different opening lines. Options: both, thread_only, linkedin_only. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Post-to-Thread Converter](https://creatorskills.co/create/post-to-thread-converter) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
