# Prepare Analytics Translator

Product description: Paste your YouTube, TikTok, or Instagram numbers and get back a one-page decision brief: what's working, what's costing you views, and the three things to change before your next upload.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Your analytics | Required | Paste it however you have it: typed numbers ("12K views, 8.2% CTR, 4:12 AVD"), a copy-pasted YouTube Studio or TikTok table, a CSV dump, or just a description of what your retention graph looks like. |
| Exported analytics file | Optional | Optional: upload the CSV export from YouTube Studio, TikTok Analytics, or Instagram Insights instead of pasting it. |
| Platform | Optional | Leave blank and we'll work it out from the metric names in your data. Options: youtube, tiktok, instagram, multiple. |
| Date range | Optional | Example: last 28 days, or March 1-31. Used to label the report and to check for seasonal effects. |
| Audience size | Optional | Benchmarks shift at every stage, so this changes which numbers count as good for you. Options: under_1k, 1k_10k, 10k_50k, 50k_250k, over_250k. |
| Niche | Optional | Tech, finance, gaming, beauty, fitness: RPM and CTR benchmarks vary wildly by niche. |
| What are you trying to work out? | Optional | Example: why my views dropped this month, or whether my new thumbnail style is working. We'll lead the report with it. |
| Last period's numbers | Optional | Paste the same metrics from your previous report or last month and we'll track what moved, not just where you are. |
| How deep should we go? | Optional | Advanced skips the definitions and reads retention curve shape, CTR by traffic source, and the RPM/CPM gap. Auto infers it from how you describe your data. Options: auto, standard, advanced. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Analytics Translator](https://creatorskills.co/create/analytics-translator) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
