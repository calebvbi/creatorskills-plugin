# Prepare Faceless Channel Launch System

Product description: Pick the faceless niche that actually pays, name and position the channel, and walk away with 30 days of video ideas already grouped into batch sessions you can film in one sitting.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What you have so far | Required | Your interests, skills, what you already know a lot about, or the niche you have already picked. "I read three finance newsletters a week and used to work in insurance underwriting" gives us a niche shortlist nobody else would get; "I want to make money on YouTube" gives us the same five niches everyone else got. |
| Niches you are already considering | Optional | One per line, up to five. Leave it blank and we shortlist five from your starting point and say why each one made the list. |
| Hours a week you can actually give this | Optional | This sets the upload cadence and the size of the 30-day plan, and it is the number most plans get wrong. A 4-videos-a-week calendar built for someone with 5 hours is a calendar they quit in week three. Options: 2, 5, 10, 20. |
| Uploads per week you are aiming for | Optional | If this and your available hours disagree, we say so and plan to the hours rather than quietly shrinking every video. Options: 1, 2, 3, 5. |
| Voice tool you use or plan to use | Optional | Changes which niches score well on delivery and how the batch sessions are grouped. Undecided is a fine answer: we score AI-voice fit either way. Options: elevenlabs, openai_tts, murf, play_ht, own_voice, undecided. |
| Channel you already have | Optional | Name, current positioning, subscriber count, what has worked and what has not. Paste it and we build on the recognition you already have instead of repositioning you away from it. |
| What you want the channel to earn from first | Optional | Weights the niche scorecard. An affiliate-first channel and an AdSense-first channel do not want the same niche even at the same CPM. Options: adsense, affiliate, digital_products, sponsorships, lead_generation. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Faceless Channel Launch System](https://creatorskills.co/create/faceless-channel-launch-system) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
