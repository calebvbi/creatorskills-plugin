# Prepare YouTube Description & Chapters Pack

Product description: Turn a finished video and its transcript into the whole description box: chapters with real timestamps, two descriptions to test, a pinned comment, and the hashtags and tags, ready to paste before you hit publish.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Transcript, script, or outline | Required | Paste the transcript if you have one: timestamps come out accurate rather than estimated. A script, an outline, or even a bullet list of what you covered all work; we mark the timestamps as estimates so you can fix them after one watch-through. |
| Video title | Optional | The title as it will actually publish. The description expands on the title's promise rather than repeating it, so we need to know what it already says. |
| Runtime | Optional | Example: 14:20, or about 12 minutes. Without it we estimate from word count at 140 words per minute plus a 15% buffer for B-roll, and label every timestamp as an estimate. |
| What kind of video is it | Optional | Chapter shape differs by format: a listicle gets one chapter per item so viewers can jump, a tutorial gets one per step because people rewatch steps. Leave it blank and we read the format from your transcript. Options: tutorial, review, listicle, educational, interview, vlog, other. |
| Target keyword | Optional | The phrase someone would actually type. It goes into the first 150 characters once, naturally, or not at all: we never wedge it in. |
| Who this video is for | Optional | "Solo podcasters" beats "creators". Written to one audience, the description reads like it was written for someone; written to everyone, it reads like a template. |
| The one thing you want viewers to do | Optional | One CTA gets written in. A block of five links at the bottom of a description converts on none of them. Options: subscribe, comment, join_email_list, download_resource, watch_next_video, buy_or_book. |
| Links to include | Optional | One per line as "name: URL". We only publish links you paste here; we never invent a URL, and anything without one is named in plain text with the link left for you. |
| Channel name | Optional | Used for the sign-off line and for the channel tag in the tag list, when it still fits the character budget. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [YouTube Description & Chapters Pack](https://creatorskills.co/create/youtube-publish-pack) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
