# Prepare KDP Book Launch Kit

Product description: Take a book idea to a publishable Amazon listing: a category and keyword plan you can verify yourself, the title, subtitle and description written out, a chapter-by-chapter outline, a cover brief a designer can quote from, and a 21-day launch with the ad campaign to run alongside it.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What the book is about, and who reads it | Required | Topic, reader, and why you are the person to write it: a paragraph is plenty. "Building a home gym on a budget, for beginners intimidated by expensive equipment; I've run a fitness channel for three years" gives us everything the listing needs. |
| What you are publishing | Optional | Ebook-only is the fastest and the right first move for most authors. Paperback adds a spine, a back cover and print costs to the brief. Defaults to ebook and paperback. Options: ebook_only, ebook_and_paperback, ebook_paperback_hardcover. |
| How long you want it | Optional | Short books under 15,000 words work well for a specific how-to and can be written in weeks. Category norms matter more than preference here, and we will say if your target is off for the category. Options: short_under_15k, standard_20k_40k, full_50k_plus. |
| The audience you already have | Optional | Newsletter size, channel subscribers, community: "15K newsletter subscribers". This decides whether launch week has a real velocity push behind it or has to be built from ads, and it is the only source for any audience number in the output. |
| Why you can write this | Optional | The author bio and the description's proof line are written from this box and nothing else. Years, results, what you have built. If you leave it blank we write the honest short version rather than inventing a background. |
| Books already selling in this space | Optional | Titles you have actually seen on Amazon, with anything you noticed: price, page count, review count, what the cover looks like. We have no live store access, so anything you paste here is real data and everything else is a check for you to run. |
| What yours does that theirs do not | Optional | The gap you are filling. "No book covers apartments under $200" is a gap; "mine is better written" is not. Leave it blank and we propose angles from your topic, clearly marked as proposals for you to verify. |
| What you can do in launch week | Optional | Email to your list, a video, ARC readers you already know, a podcast appearance: whatever is genuinely available. The 21-day calendar is written for what you actually have, not for an author with a publicist. |
| What you can spend on ads | Optional | Amazon ads are the one lever that works without an audience, and they are also the fastest way to spend money on nothing. "None" is a legitimate answer and changes the launch plan rather than shrinking it. Options: none, under_5_a_day, five_to_ten_a_day, over_ten_a_day. |
| How you write | Optional | The description and the bio are the only writing most buyers see before deciding. Pick match_my_channel if we have your voice on file. Options: warm_direct, blunt_practical, generous_teacher, wry_understated, high_energy, match_my_channel. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [KDP Book Launch Kit](https://creatorskills.co/create/kdp-book-launch-kit) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
