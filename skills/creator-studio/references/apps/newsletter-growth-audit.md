# Prepare Newsletter Growth Audit & Subscriber Conversion Pack

Product description: Find out why your list stopped growing: the three blockers ranked by what fixing them is worth, and get the subscriber CTAs and pitch posts to publish on every platform you are already on this week.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What your newsletter is about | Required | "Weekly teardowns of indie SaaS pricing pages, for solo founders" beats "business". Every CTA we write names the thing a subscriber gets, and it can only be as specific as this box. |
| How many subscribers you have now | Required | A number and roughly how long you have been publishing: "210, about eight months". Under 500 is the situation this was built for, and the advice changes rather than gets nicer as the number grows. |
| Where you already have an audience | Required | One per line with rough follower counts: X, LinkedIn, Instagram, TikTok, YouTube. We only write CTAs for platforms you are actually active on; a pitch post for an account you abandoned is worse than none. |
| What a subscriber gets that a follower does not | Optional | This is the single hardest question and the one every CTA turns on. If the honest answer is "the same stuff, by email", say that: we will tell you so plainly in the audit rather than writing copy around it. |
| What you offer people for subscribing | Optional | The name of it, or "nothing". Both are real answers. If it is a generic "10 tips" we will say so, and the lead magnet itself is built by Newsletter Conversion Engine, not here. |
| Where your subscribers come from now | Optional | "No idea" is the most common answer and is itself a finding: it usually means there is no link anywhere trackable, which is blocker number one more often than content quality is. Options: social_media, word_of_mouth, existing_audience, search, cross_promotion, mixed, no_idea. |
| What your last three issues were about | Optional | Subjects or rough topics, one per line. This is how we tell whether the newsletter has a recognisable promise or reads as a personal blog, and a promise is what a CTA can point at. |
| A recent post that did well | Optional | Paste one, from any platform. Two jobs: it is the voice we match, and it is the post we write the appended subscriber CTA for: a CTA bolted onto a real post beats one written in the abstract. |
| How often you send | Optional | "Irregular" is worth admitting. It is a growth blocker on its own: people do not subscribe to something they cannot predict, and it changes what the CTA can honestly promise. Options: weekly, twice_weekly, every_two_weeks, monthly, irregular. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Newsletter Growth Audit & Subscriber Conversion Pack](https://creatorskills.co/create/newsletter-growth-audit) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
