# Prepare Instagram Reels Script Writer

Product description: Turn a topic into two shot-ready Instagram Reels scripts timed to the second, with hook options, a search-ready caption, on-screen text callouts, and audio picks.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What is this Reel about? | Required | Be specific: "how to write better hooks" beats "content tips". One or two sentences is plenty. |
| Length | Optional | Seconds. Defaults to 30 if you skip it: the length most Reels tips land best at. Options: 15, 30, 60, 90. |
| Goal for this Reel | Optional | Drives the CTA. Only one CTA gets written, whichever you pick. Options: follows, saves, comments, link_in_bio, profile_visits, email_signups. |
| Format | Optional | How you plan to shoot it. Changes the visual direction, not the words. Options: talking_head, text_overlay, tutorial, pov, b_roll_voiceover. |
| Niche and audience | Optional | What you make content about and who watches: e.g. "personal finance, for 20-somethings with their first salary". Calibrates vocabulary and how much you can assume they know. |
| Anything else worth using | Optional | A number, a result, a story beat, a product name. Concrete detail is what makes a Reel script sound like you and not like a template. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Instagram Reels Script Writer](https://creatorskills.co/create/instagram-reels-script-writer) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
