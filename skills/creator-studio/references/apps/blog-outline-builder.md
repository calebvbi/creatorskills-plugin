# Prepare Blog Outline Builder

Product description: Turn a keyword into a blog post you can draft in one pass: three working titles, the search intent behind them, and every section written down to the specific claim it makes and the line it opens on.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Your topic or target keyword | Required | "AI blog outline generator" or just "how to repurpose YouTube videos into blog posts". Either works: a keyword gets an SEO-shaped structure, a plain topic gets a reader-shaped one. |
| Who this post is for | Required | "Newsletter writers moving into SEO content" beats "creators". Every section's claim is aimed at one reader, and a vague reader produces vague claims. |
| What you want the post to do | Optional | This decides the CTA and how hard the post sells. Leave it on "pick for me" and we choose from the search intent behind your keyword instead of guessing. Options: organic_traffic, lead_generation, authority_building, product_education, pick_for_me. |
| The angle you want to take | Optional | The opinion, the contrarian take, or the specific experience you are writing from. This is the difference between a post that reads like yours and a post that reads like everyone's. |
| What you would point a reader to at the end | Optional | A newsletter, a template, a course, a call. We write one primary CTA and one low-friction fallback for it. Leave it blank and the CTA becomes a subscribe ask rather than an invented product. |
| Posts you have already published | Optional | Titles and URLs, one per line. Internal link suggestions come only from this list: we will not invent an anchor pointing at a page you have not written. |
| Something you wrote that sounds like you | Optional | Two paragraphs of a past post is enough. This is what the drafted opening lines are matched against, and it is the biggest single difference between usable copy and filler. |
| Roughly how long the finished post should be | Optional | This sets how many sections the outline carries and how much each one is expected to hold, so the finished draft lands near the length you wanted rather than double it. Options: under_1000, 1000_to_1500, 1500_to_2500, over_2500, undecided. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Blog Outline Builder](https://creatorskills.co/create/blog-outline-builder) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
