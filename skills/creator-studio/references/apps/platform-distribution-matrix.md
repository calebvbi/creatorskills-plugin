# Prepare Platform Distribution Matrix

Product description: Decide which platforms are actually worth your week: a ranked shortlist with the ones to drop named, the format and cadence for each one you keep, and a calendar whose hours add up to the hours you said you have.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What you make and who it is for | Required | Content type, niche, and audience in a few sentences: "20-minute weeknight cooking videos for people who cook after work, mostly 28-45, US and UK". The format you actually produce is what decides which platforms are even reachable for you. |
| Where your audience already is | Optional | Your anchor platform. Everything else gets planned as repurposing off it, because that is the only version of multi-platform a solo creator sustains. Options: youtube, youtube_shorts, tiktok, instagram, linkedin, twitter_x, newsletter, podcast, none_yet. |
| Where you post now and how often | Optional | One line per platform: "TikTok: 2 a week, 900 followers, mostly flat". Include the inactive ones. Knowing which accounts already exist changes whether a platform is a start-up cost or a restart. |
| Hours a week you actually have for content | Optional | The single most load-bearing answer here. Every recommendation is costed against it, and the plan is cut to fit rather than handed to you aspirationally. Options: under_5, five_to_10, ten_to_20, twenty_to_40, over_40. |
| Who does the work | Optional | An editor changes what is realistic far more than an extra five hours does. Say so and the cadence shifts accordingly. Options: solo, solo_plus_editor, small_team, full_team. |
| What you are optimising for | Optional | A creator chasing sponsorship revenue gets a different matrix from one building an email list: different platforms, different formats, different definition of a good week. Options: growth, revenue, community, email_list, mixed. |
| Your current numbers | Optional | Follower counts, average views, engagement rates per platform, however you have them. Used to calibrate the ranking against reality rather than against platform averages. We never invent a number you did not paste. |
| Platforms you will not do | Optional | "No TikTok, no on-camera": hard constraints, not preferences. We rank around them instead of recommending something you have already ruled out. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Platform Distribution Matrix](https://creatorskills.co/create/platform-distribution-matrix) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
