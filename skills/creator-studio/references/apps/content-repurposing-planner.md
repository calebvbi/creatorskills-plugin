# Prepare Content Repurposing Planner

Product description: Turn one long video, episode, or post into a decided plan, which moments to cut, which platform each belongs on, a brief your editor can work from, and the three to make first this week.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| What you made | Required | Paste the transcript, the outline, or just describe it: "28-minute video on why I stopped charging hourly, I show my actual invoice structure and how I handle pushback." The more specific the moments you name, the more specific the plan. |
| What kind of content is it | Optional | Leave blank and we'll work it out from your description. Options: youtube_video, podcast_episode, blog_post, webinar, livestream, other. |
| Runtime or length | Optional | Example: 28 minutes, or 1,800 words. Longer source material carries more pieces: a 12-minute video will not support ten of them. |
| Where you actually publish | Optional | YouTube, Instagram, LinkedIn, X, TikTok, newsletter, podcast: whichever you're really active on. This is the one question we'd otherwise ask you: we'd rather focus the plan there than spread it across everything. |
| Who it's for | Optional | Beginners, working professionals, a specific niche. Changes which angle each piece takes, not just who we address. |
| How much time you have | Optional | A solo creator with five hours gets a ruthlessly short plan weighted to quick wins. Say so and we'll prioritise accordingly. Options: solo_under_5h, solo_5_15h, small_team, full_team. |
| Narrow it to one format family | Optional | Only want newsletter ideas, or only short-form? Pick one and the whole plan narrows. Defaults to all formats. Options: all, short_form_video, written, visual, audio. |
| Link to the original | Optional | Optional. Used only to label the plan and to name the piece in your history: we plan from your description, not from the link. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Content Repurposing Planner](https://creatorskills.co/create/content-repurposing-planner) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
