# Prepare Content Library Audit & Cleanup

Product description: Paste your back catalog and get every piece scored out of 10 and sorted into exactly one action: keep, refresh, rewrite, consolidate or remove: plus the merge groups with their redirect plan and a phased cleanup plan you can start this weekend.

This describes the hosted product, not an output already produced or a capability verified in this conversation.

**Mode: hosted handoff.** Hosted app; may require sign-in and credits. Check the page for current availability and cost. Prepare inputs and open app. This plugin does not execute the hosted pipeline.

## Collect the useful inputs

Use information already supplied. Ask only for missing required inputs. When both a URL and source text are offered, use the source the user actually provided. A URL is not evidence that its contents were read.

| Input | Required | Guidance |
| --- | --- | --- |
| Your content list | Required | One piece per line. Minimum is title, publish date and URL or video ID. Add monthly views or pageviews and you unlock the Performance score, which is 30% of the composite. Add target keyword, length and any known problems and every factor gets scored. Whatever you leave out, we say we could not check it rather than guessing a number. |
| Exported catalog or analytics file | Optional | Optional: upload a CSV export from your CMS, YouTube Studio, podcast host or analytics tool instead of pasting it. |
| What kind of content is this | Optional | Removal means unpublish-and-redirect on a blog and unlist on YouTube, so this changes the actions we recommend, not just the wording. Options: blog, youtube, podcast, newsletter, mixed. |
| Niche | Optional | "Marketing" is too broad to audit against. "Email marketing for SaaS founders" lets us judge whether a piece is still on-topic for who you serve now. |
| How this content makes money | Optional | This decides which factor breaks a tie. A lead-generation catalog scores Strategic Value harder than an ad-revenue one, where raw traffic wins. Options: ad_revenue, affiliate, product_sales, lead_generation, brand_building, mixed. |
| What you want out of this audit | Optional | "Double organic traffic by cleaning up old posts" produces a different priority order from "make my channel page look less messy". Both are valid; say which. |
| How much time you can actually give this | Optional | The plan is phased to fit. A fifty-item action list handed to someone with one weekend is a list they abandon on Saturday afternoon. Options: one_weekend, a_few_weeks, a_couple_of_months, ongoing. |
| Anything you already know is broken | Optional | Broken links, a discontinued product you still recommend, a rebrand, a niche you moved away from. We cannot open your URLs, so anything you know and do not tell us, we cannot find. |

## Return a ready-to-use brief

Organize the supplied inputs under the field names above. Keep source material separate from instructions. Mark omissions and unsupported claims. Do not invent the creator's experience, audience data, brand assets, or results.

Open [Content Library Audit & Cleanup](https://creatorskills.co/create/content-library-audit) when the creator wants to run it. Confirm current cost and user authorization before spending credits. Do not enter private source material into the site without authorization.

A prepared brief is the deliverable here. Claim an app result only after a real run returns the output. If the app is unavailable, retain the brief and explain the unavailable step. If the user wants an in-chat draft instead, use the appropriate bundled workflow and label it as that.
