# Thumbnail A/B Analyzer: observed difference before a winner claim

## Supplied input

Version A, “10 Mistakes Beginner Streamers Make,” has 2,847 impressions and 312 clicks. Version B, “I Tried Affiliate for 30 Days: This Is What Happened,” has 2,903 impressions and 428 clicks. The creator asks which wins. No assignment method, dates, source mix, underlying-video identity, image files, viewing guardrails or next-video topic is supplied.

## Calculation

- A: 312 ÷ 2,847 ≈ 10.96% CTR.
- B: 428 ÷ 2,903 ≈ 14.74% CTR.
- Observed difference: about 3.78 percentage points, or 34.53% relative using unrounded rates.

B has higher observed CTR in these counts. This does not establish a controlled winner, explain viewer motivation or isolate the thumbnail from the title and underlying content.
